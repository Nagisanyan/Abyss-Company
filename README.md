# Abyss Company

Base de site vitrine statique pour presenter Abyss Company, son identite et ses projets.

## Contenu

- `index.html` : page principale du site.
- `projects.html` : page de presentation des projets.
- `styles.css` : design responsive.
- `script.js` : menu mobile.
- `assets/` : visuels originaux du site.

## Publication GitHub Pages

1. Dans GitHub, va dans `Settings` puis `Pages`.
2. Dans `Build and deployment`, choisis `Deploy from a branch`.
3. Choisis la branche `main` et le dossier `/root`.
4. Sauvegarde.
5. GitHub donnera une URL publique au site.

## A personnaliser

- Remplacer les liens `Discord` et `GitHub` dans `index.html`.
- Ajouter une page dediee a Aegis.
- Ajouter une page changelog complete.
- Ajouter un logo officiel si Abyss Company en a un.
